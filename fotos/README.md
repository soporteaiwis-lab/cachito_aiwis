# Fotos

Sube aquí las fotos de Cachito con estos nombres para que aparezcan en la web:

- `cachito-01.jpg`
- `cachito-02.jpg`
- `cachito-03.jpg`
- `cachito-04.jpg`
- `cachito-05.jpg`
- `cachito-06.jpg`

Formato recomendado: JPG vertical 4:5, mínimo 1080×1350. Para agregar más, suma nombres a la lista `fotos` dentro de `index.html` (busca `cachito-06.jpg`).

Usa solo fotos con permiso de Cachito o de quien las tomó.
